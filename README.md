# JupyterHub Docker Setup

Изначально был форк, но сильно изменился.

Есть два конфига для спавнера докера просто и с маунтами. Советую использовать с маунтом.

Чтобы поднять - откопируй данную репу. В `docker-compose.yml` есть конфигурация для простого старта (сеть будет сгенерирована от имени директории, поэтому предпологается что копирование идёт через `git clone` без специфичного пути). Но вообще можно легко заменить.

```bash
docker compose up -d
```

Запустит с монтированием. Есть изначально админ пользователь - его окружение стартует в контейнере, volume выглядит как

```bash
local     jupyterhub-user-admin
```

Удобно и с привязкой к пользователю. По уму можно сделать двойное монтирование на контейнер хаба, а затем на систему, но пока немного впадлу).

Если хотите заменить на быстрый старт без монтирования - поменяйте Dockerfile (копирование конфига)
